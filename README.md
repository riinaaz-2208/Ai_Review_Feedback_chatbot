AI Review Feedback Chatbot

Project Overview

An AI-powered chatbot designed to review submitted documents, identify mistakes, provide feedback, and help track task reviews.

Features

- Assign tasks and record important dates.
- Upload TXT or PDF documents for review.
- Use Google Gemini AI to identify mistakes and suggest improvements.
- Chat with the AI about document feedback.
- Track review records.
- Download review records as a CSV file.

Technologies Used

- Python
- Streamlit
- Google Gemini API
- Pandas
- PyPDF

How to Run

1. Install Python.

2. Install the required packages:
   
   "pip install -r requirements.txt"

3. Start the application:
   
   "python -m streamlit run app.py"

4. Enter your Gemini API key in the app's sidebar to use the AI review feature.

Security Note

Never upload your Gemini API key to GitHub. Enter it privately in the application when required.
